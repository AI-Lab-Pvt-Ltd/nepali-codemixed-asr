# Security

Do not post credentials, private recordings, transcripts or exploitable vulnerability details in public issues. Use the repository's private vulnerability reporting feature when enabled, or contact AI Lab Pvt. Ltd. through an established private company contact. A dedicated security address and supported release policy have not yet been published.

Load checkpoints and model code only from sources you trust. Model deserialization and custom model code can execute code. Keep access tokens in your environment, and review logs and prediction files before sharing them.

Maintainers must configure a private reporting channel before public release; see docs/RELEASING.md.
